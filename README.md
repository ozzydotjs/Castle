# Castle

Castle is a .NET MAUI Blazor Hybrid music player built with C#, Blazor, LiteDB, ManagedBass, TagLibSharp, YoutubeExplode, and yt-dlp/ffmpeg support.

## Features

- Local music library scanning
- Audio playback with queue support
- Playlists
- Recently played history
- Lyrics support
- Metadata editing
- Theme system
- Download queue
- Last.fm scrobbling support
- Update checker

## Requirements

- .NET 10 SDK
- Windows 10/11
- yt-dlp.exe
- ffmpeg.exe / ffprobe.exe
- bass.dll

## Notes

Runtime binaries such as yt-dlp, ffmpeg, ffprobe, and bass.dll are not included in the repository. They must be placed locally before running or packaging the app.
